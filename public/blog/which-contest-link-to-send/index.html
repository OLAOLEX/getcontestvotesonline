Which contest link should you send for a quote?

A direct entry link helps us review the right contestant, category and round.

Start at the actual voting destination

Open the organiser’s current ballot and find the entry you want to support. Where the entry has its own page, copy that address. A link to the organiser’s homepage or a social announcement can leave the important details unclear.

For example, a local business might appear in three award categories. Sending the main award page and asking for “500 votes” does not identify which category the request concerns. Add the business name as printed on the ballot, its location and the intended category.

If there is no public link

A native social poll may be visible only within a conversation or group. Describe the poll question and exact answer option instead. Explain the access conditions; never send your account password or another participant’s private messages.

Check the round before requesting support

Names and links can stay the same when a competition moves from nominations to voting. State the current stage and closing time, including the time zone. If you cannot confirm a detail, say so. We can review the request without treating an assumption as an organiser instruction.

A screenshot can help identify a ballot, but it does not replace a usable link or establish that a vote has been accepted.
